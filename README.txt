# Alien Hunter: Extermination — Game Jam Build

Open `index.html` in a modern browser. No server or dependencies are required.

Controls:
- Desktop: WASD / Arrow keys to move, mouse to aim, click or Space to fire.
- Mobile: drag the MOVE circle and tap/hold FIRE.
- Press H on desktop to launch the hacking mini-game.

Gameplay:
- Survive escalating waves of aliens.
- Drone, spitter, and brute enemy types.
- Score, ammo, health, wave progression, supply drops.
- Hack mini-game restores ammo, health, and grants temporary rapid fire.
- Reach 60 kills to win.
